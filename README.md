# Terminal Portfolio

> A minimal terminal-based portfolio

## Features

- ASCII art name display
- Live GMT time and date
- Contact information and links
- Tech stack overview
- Project showcase
- Clean, minimal design

## Usage

Run it:
```bash
npx tirthh
```

Or install globally:
```bash
npm install -g tirthh
tirthh
```

## What's included

- Contact details
- Current projects
- Skills and technologies
- Location info
- Real-time clock

## Built with

- **chalk** - Terminal colors
- **boxen** - Borders
- **gradient-string** - Color gradients
- **figlet** - ASCII text
- **cli-cursor** - Cursor control

## Development

Clone and install:
```bash
git clone https://github.com/TirthDhandhukia30/portfolio-CLI.git
cd portfolio-CLI
npm install
```

Test locally:
```bash
npm link
tirthh
```
