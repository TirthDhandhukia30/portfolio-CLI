# ✨ Tirth Dhandhukia - Stunning Terminal Portfolio

> A beautiful, animated terminal-based portfolio with ASCII art, gradients, and stunning visuals

## 🚀 Features

- 🎨 **Stunning ASCII Art** - Eye-catching name display
- 🌈 **Gradient Colors** - Beautiful color transitions
- ⚡ **Animated Elements** - Dynamic visual effects
- 🔥 **Tech Stack Display** - Showcase your skills with emojis
- 📱 **Responsive Design** - Works on all terminal sizes
- 🎯 **Easy to Use** - Just one command!

## Usage

### Quick Run (Recommended)
```bash
npx tirthh
```

### Global Installation
```bash
npm install -g tirthh
tirthh
```

## 🎬 Preview

Experience the stunning terminal portfolio with:

## 🛠️ Built With

- **chalk** - Terminal colors
- **boxen** - Beautiful boxes
- **gradient-string** - Stunning gradients
- **figlet** - ASCII art text
- **cli-cursor** - Cursor management

## 📦 Development

Clone the repository:
```bash
git clone https://github.com/tirth/tirthh.git
cd tirthh
```

Install dependencies:
```bash
npm install
```

Test locally:
```bash
npm link
tirthh
```
